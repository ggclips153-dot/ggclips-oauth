GGclips Automation

A self-hosted scheduling dashboard for GGclips, a gaming highlights channel. It publishes the channel's own clips to the channel's own connected social accounts, at times chosen in advance.

What it does

GGclips Automation is a single-operator tool. The channel owner adds a finished video clip, writes the caption and first comment, chooses the posting options each platform requires, and sets a date and time. At that time the dashboard publishes the clip through each platform's official API.

  • Schedules a clip once and publishes it across the channel's connected accounts
  • Posts the caption and an optional first comment
  • Reads back view, like, comment and share counts so performance can be compared
  • Requires the operator to confirm every post before it is armed to go out

How TikTok is used

The dashboard uses TikTok Login Kit so the channel owner can authorize their own TikTok account, and the Content Posting API to publish a video the owner has selected. Before anything is posted, the dashboard asks the owner to choose the video's privacy level, decide whether comments, Duet and Stitch are allowed, and declare any commercial content. Nothing is posted without that confirmation.

It also uses video.list to read back public metrics for videos it posted, so the channel owner can see how a clip performed.

Where it runs

The dashboard is self-hosted: it runs locally on the channel owner's own computer rather than as a hosted service. There is no shared server, no other users, and no account to sign up for. This website exists to document the tool and to receive the authorization redirect.

GGclips Automation is an independent personal project. It is not affiliated with, endorsed by, or sponsored by TikTok, YouTube, Meta, or any other platform it connects to.
