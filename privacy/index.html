Privacy Policy

Last updated 15 September 2026

GGclips Automation is a self-hosted tool used by one person to publish their own videos to their own social accounts. It has no user accounts, no hosted service, and no other users.

Who this covers

The only person whose data the software handles is its operator — the owner of the GGclips channel, who installs and runs it on their own computer. There is no sign-up, and no one else can use the installation.

What the software stores

All of the following is stored in a database file on the operator's own computer. None of it is transmitted to the developer, and there is no remote server:

  • Authorization tokens for the platforms the operator connects, used only to publish and to read back metrics for their own posts
  • Post details the operator enters: the video file's location, caption, optional first comment, tags, posting options, and scheduled time
  • Identifiers of posts it published, so metrics can be matched to the right video
  • Performance metrics read back from the platforms — view, like, comment and share counts for the operator's own posts

What it sends, and to whom

When the operator schedules a post, the software sends that video and its caption to the platform the operator chose, using that platform's official API and the operator's own authorization. That is the only outbound transfer it makes. It sends nothing anywhere else.

Data handled by a platform after it is posted is governed by that platform's own privacy policy, not this one.

What it does not do

  • No data is sold, shared, or given to any third party
  • No advertising, tracking, profiling, or telemetry
  • No data is collected about anyone other than the operator
  • This website sets no cookies and runs no analytics

Retention and deletion

Because everything lives in a local database file, the operator controls retention directly: deleting a scheduled post removes its record, and deleting the database file removes everything. Authorization can be revoked at any time from the platform's own settings, which immediately stops the software's access regardless of what is stored locally.

Security

Tokens are held in the local database on the operator's machine and are protected by that computer's own user account and disk security. Because there is no hosted component, there is no shared database that could expose one user's data to another.

Changes

If the software's data handling changes, this page will be updated and the date above revised.
